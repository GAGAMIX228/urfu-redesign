# Один УрФУ — один вход

Прототип редизайна сайта Уральского федерального университета для конкурса «Взломай веб-дизайн».
Фирменный стиль «Самоцветы Урала». Автор — Кирилл Бурдин.

**Открыть сайт:** https://gagamix228.github.io/urfu-redesign/

- `index.html` — список всех экранов
- `Concept.dc.html` — концепция: принципы, стиль, было → стало
- `Logo.dc.html` — логотип, палитра, шрифт
- `site.css` — общий стиль всего сайта: цвета, шрифт, элементы

Сайт статический и работает без интернета и внешних сервисов: шрифт IBM Plex Sans лежит в папке `fonts/`.
Значения в квадратных скобках — места для данных, которые заполняются при внедрении.
